# React To-Do App

A two-page task management app built with React, TypeScript, Vite, and React Router.

## Features

- Home page with navigation to the tasks page
- Add, edit, and delete tasks
- Mark tasks as completed
- View total, completed, and remaining task counts
- Save tasks in browser local storage
- Responsive design

## Run locally

```bash
npm install
npm run dev
```

Open the local URL displayed in the terminal.

## Build

```bash
npm run build
```

Tasks are stored in the current browser and are not synced across devices.
